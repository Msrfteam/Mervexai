## Install

```bash
npm install -g mervexai
```

Native binaries for **Windows, Linux and macOS** (x64 + arm64) — no runtime dependencies.

## Quick start

```bash
mervexai --help
```

You need a free API key — grab one at **https://mervex.cc.cd/auth** (sign-up takes seconds, no credit card).

## What is Mervex?

Mervex is a free AI platform with **100+ models behind one OpenAI-compatible key**:

- **Chat** — `POST https://api.mervex.cc.cd/v1/chat/completions` (OpenAI format)
- **Models** — `GET https://api.mervex.cc.cd/v1/models` (public list)
- **Auto-Decision API** — millisecond probabilistic decisions (yes/no, option pick, scoring, image classification) — 10,000 lifetime requests per user, free
- **Live monitoring** — every model's success rate, latency and 14-day history at [mervex.cc.cd/models](https://mervex.cc.cd/models)
